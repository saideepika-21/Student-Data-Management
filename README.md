# Student Data Management System

## 📋 About the Project
A Student Data Management System designed to efficiently store, 
organize, and manage student records. This system allows users to 
add, update, delete, and view student information in a simple and 
user-friendly interface.

## ✨ Features
- Add new student records
- View all student data
- Update existing student information
- Delete student records
- Search/filter students easily

## 🛠️ Technologies Used
- Language: Python
- Database:JSON
- IDE/Editor:Visual Studio Code (VS Code)
